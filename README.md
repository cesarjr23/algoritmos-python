# Algoritmos em Python

Repositório dedicado ao estudo e à prática de **lógica de programação utilizando Python**, reunindo exercícios, desafios e atividades desenvolvidos ao longo da minha jornada de aprendizado.

O objetivo é consolidar os fundamentos da programação por meio da resolução de problemas, tanto em atividades acadêmicas quanto em estudos independentes.

## Sobre o repositório

Este espaço reúne diferentes exercícios de programação, incluindo:

- **Atividades acadêmicas:** exercícios e avaliações realizados durante minha formação em tecnologia.
- **Listas de exercícios:** problemas de lógica e programação utilizados para aprofundar os conteúdos estudados.
- **Desafios de programação:** atividades voltadas ao desenvolvimento do raciocínio lógico e à resolução de problemas.
- **Prática independente:** exercícios desenvolvidos para experimentar conceitos e aprimorar minhas habilidades em Python.

O repositório será atualizado conforme novos conteúdos forem estudados e novos desafios forem resolvidos.

## Objetivo de aprendizado

Utilizar a prática constante como forma de desenvolver o raciocínio lógico, aprimorar a capacidade de resolver problemas e construir uma base sólida para o desenvolvimento de software.

Este repositório também funciona como um registro da minha evolução, permitindo acompanhar os conhecimentos adquiridos e revisitar soluções anteriores.
